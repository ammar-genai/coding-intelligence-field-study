Acceptance contract

  • Adversarial ordering tests pass
  • Restart recovery is exactly-once
  • Stale events cannot regress state

Escalation rules

  • No meaningful edit by the stage deadline → replace the worker.
  • Scope drift → reject the patch before evaluation.
  • Tests fail to improve → preserve the attempt and escalate.
  • Medium or higher review finding → repair and rerun the unchanged gate.
  • Cost ceiling reached → stop; never spend silently.
WHAT IS STANDARD HERE

Representative task families, controlled execution.

The pack follows common evaluation patterns: repository-level issue resolution, test generation, visual software repair, end-to-end product work, terminal operations, performance challenges, long-horizon engineering, and managerial decisions.

Independent gate
